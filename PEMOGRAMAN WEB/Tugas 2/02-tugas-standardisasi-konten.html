Ringkasan Arah Riset Departemen

Kegiatan riset Departemen Teknik Informatika diarahkan pada pemanfaatan Machine Learning & Internet of Things untuk persoalan kewilayahan Sulawesi Selatan, khususnya pemantauan pesisir dan pengelolaan data kota Makassar. Model klasifikasi yang dikembangkan diuji pada rentang suhu permukaan laut 26°C hingga 32°C dengan galat pengukuran sensor sebesar ±0,4 satuan, sedangkan ambang signifikansi statistik ditetapkan pada α ≤ 0,05.

Luaran model disajikan ke publik melalui antarmuka web yang memakai elemen semantik seperti <table> dan <figure>, sehingga data tetap terbaca oleh pembaca layar, mesin pengindeks, maupun perangkat bergerak dengan jaringan terbatas. Agenda lanjutan mencakup kompresi model, efisiensi daya simpul sensor, pemrosesan bahasa daerah, hingga tata kelola data terbuka … yang seluruhnya diarahkan pada penerapan langsung di lingkungan kampus dan pemerintah daerah.

Bidang Keahlian Dosen

Bidang keahlian diurutkan menurut prioritas pengembangan departemen, dengan rincian topik pada tiap bidang.

  1. Kecerdasan Artifisial Terapan
    • Pembelajaran mendalam untuk data runtun waktu
    • Deteksi anomali pada aliran data sensor
    • Pemrosesan bahasa alami untuk bahasa daerah
  2. Sistem Tersemat dan Internet of Things
    • Rancang bangun simpul sensor berdaya rendah
    • Protokol komunikasi nirkabel jarak jauh
    • Komputasi tepi untuk inferensi luring
  3. Rekayasa Perangkat Lunak
    • Arsitektur layanan mikro
    • Pengujian otomatis dan integrasi berkelanjutan
    • Aksesibilitas web dan standardisasi konten
  4. Sains Data dan Visualisasi
    • Praproses dan pembersihan data lingkungan
    • Analisis spasial wilayah pesisir berbasis peta
    • Penyajian data yang ramah pembaca layar

Metodologi Riset

Seluruh publikasi di atas mengikuti alur kerja yang sama, mulai dari perumusan masalah sampai diseminasi hasil, dengan satu putaran perbaikan bila evaluasi belum memenuhi ambang batas.
